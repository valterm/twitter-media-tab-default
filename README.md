# Twitter Media Tab Default to Pictures
The new media tab defaults to videos which sucks.
At least on web this extension makes it default to Photos.

## Install

1. Download the .crx from releases
2. Open `chrome://extensions`
3. Enable developer mode
4. Drag-and-drop the downloaded file into the page
5. Accept the safety check
